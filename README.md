A tiny program that writes a single funny line to `/output/entry.txt`. The line is a deadpan complaint from a smart fridge whose milk has expired.

## Run it

```sh
node main.ts
```

It writes exactly one line (111 characters, no trailing newline) to `/output/entry.txt` deterministically — the same bytes every run, with no input, no network, and no secrets.
